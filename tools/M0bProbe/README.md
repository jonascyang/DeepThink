# M0b 只读探测程序

一次性的探测工具，对应 [PRD](../../docs/PRD.md) §15 的 M0b。它是一个菜单栏小程序，在你平时干活时挂着运行，回答六个问题：

1. **可读率**：各 App 用辅助功能能读到多少字，哪些读不到；Electron / Chromium 应用开启 `AXManualAccessibility` 前后各读到多少。
2. **多窗口**：同时可见的窗口能不能分别读到，位置、屏幕和焦点能不能拿到。
3. **OCR**：读不到文字的窗口，截图加本机识别要多久、能识别出多少字。
4. **开销**：持续采样时，探测程序自身的 CPU 和内存占用。
5. **授权保留**：用固定的自签证书重新构建、重新安装后，辅助功能授权还在不在。
6. **数据量**：每小时新增多少文字，用来估算白天整理的模型用量。

## 隐私

- **只写统计数字**：字数、耗时、窗口尺寸、App 的 bundle id 等。屏幕文字、窗口标题和网址都不写入磁盘。文字只在内存里保留一份，用来和上一次采样对比、计算新增字数。
- OCR 的截图识别完就丢弃，不落盘。
- 密码输入框不读；1Password、Bitwarden、LastPass、系统「密码」App 和钥匙串访问整个跳过。
- 程序里没有任何联网代码。
- 数据存放位置：`~/Library/Application Support/ThinkMyDay-M0bProbe/`。

## 使用步骤

### 1. 创建固定签名证书（只需一次）

```bash
./scripts/make-signing-cert.sh
```

脚本会在登录钥匙串里创建自签证书「ThinkMyDay Local Signing」，并把它设为可信的代码签名证书。设为可信这一步，macOS 会要求输入密码。生成的文件放在仓库根目录的 `signing-local/` 下，这个目录已被 git 忽略。

### 2. 构建并安装

```bash
SIGN_IDENTITY="ThinkMyDay Local Signing" ./scripts/build-app.sh
```

装好的程序在 `~/Applications/ThinkMyDay-M0bProbe.app`。

### 3. 打开并授权

打开这个 App，菜单栏会出现「M0b」，然后按提示授权：

- **辅助功能**：必需。在「系统设置 → 隐私与安全性 → 辅助功能」里打开。
- **屏幕录制**：OCR 需要。打开后可能要退出 App 再重新打开才生效。
- **自动化 → Google Chrome**：第一次读取 Chrome 网址时会弹窗，选允许。

菜单栏图标显示「M0b ⚠︎」，说明辅助功能还没授权。

### 4. 正常干活 1 到 2 小时

尽量把这些场景都覆盖到：

- Chrome 里打开长网页、文档类网页、推特。
- 微信、飞书、Slack 等聊天工具；Cursor、VS Code、Notion 等 Electron 应用；终端；Claude 和 ChatGPT 桌面版。
- 两个窗口左右并排；窗口部分重叠；副屏上开着参考资料。

### 5. 测试授权是否保留

在第 3 步授权完成后：

1. 再运行一次第 2 步的构建命令。它会生成一个新的构建号，用同一张证书签名，并替换已安装的 App。
2. 重新打开 App，看菜单第二行是否仍然显示「辅助功能：已授权」。
3. 再重复一次。

报告里「启动与授权保留」这一节会列出每次启动时的签名信息和授权状态。

如果想做对照组：不设 `SIGN_IDENTITY` 构建一次，得到的是临时签名（ad-hoc），预期授权会丢失。测完后，到「系统设置 → 辅助功能」里把多出来的那一项删掉。

### 6. 生成报告

在菜单里点「生成报告并退出」，报告会写到 `report-<时间>.md`，并在 Finder 里自动选中。把报告交给 Claude，整理成 `docs/M0b-探测报告.md`。报告里只有统计数字。

## 注意

- 探测程序会给 Chrome 和 Electron 应用打开辅助功能开关（`AXManualAccessibility`，不行时改用 `AXEnhancedUserInterface`）。少数应用的窗口动画可能因此异常，重启那个应用即可恢复。
- 开发用的开关：`M0B_SMOKE_SECONDS=N` 运行 N 秒后自动生成报告并退出，期间不请求任何授权、不碰 Chrome；`M0B_DATA_DIR=路径` 把数据写到别的目录；`open --env M0B_DUMP_DIR=路径 …app` 把每个 App 窗口的元素结构（只有角色、位置和字数，没有文字）导出到该目录，用来排查可见性规则。
