# 复盘是和 AI 的对话，不做跑偏判定

v1 的复盘界面是类似 Claude 的对话窗口：AI 依据记录讲清这一天做了哪些事情，结合待办的勾选状态和记录里观察到的情况，帮用户找出哪件事没做完或没好好做，可以给总结性建议，用户可以追问和补充。因此模型是 P0，没有模型时只能看原始时间线，不能复盘。这推翻了 PRD v0.3 的三条原则：「v1 只还原、不评价、不给建议」「模型分析为 P1、没有模型也能用」「根据内容判定可能跑偏」。原因：Jonas 认为「跑偏」的标签对他没用，他真正想知道的是哪件事没做好；对话也比静态报告更容易发现问题，并当场补充和纠正。观察用提问的方式说出、由用户确认后再给建议，以降低误判和让人反感的风险。
