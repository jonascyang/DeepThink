# 加密每条记录的内容，而不是整库加密

记录库用 CryptoKit 的 AES-256-GCM 加密每一条事件和记录的内容，密钥存在登录钥匙串里（仅本机、首次解锁后可用）。时间、记录种类、复盘日编号不加密，用来查询和按期清理。不用 SQLCipher 整库加密。

原因：

- macOS 自带的 SQLite 不能加密。SQLCipher 要引入并编译第三方 C 库，还要为通用二进制（arm64 + x86_64）单独处理，签名和升级都更麻烦。CryptoKit 是系统自带的。
- 能看出什么、看不出什么已经足够清楚：拿到库文件但没有密钥的人，只能看出哪天、哪些时刻有记录，看不到 App、窗口标题、网址或文字。
- 删除仍然彻底：打开 `secure_delete`，删除后清空 WAL。

代价：

- 不能在 SQL 里搜索内容。以后需要搜索时，先解密再在内存里查找。
- 钥匙串里的密钥丢了，整个记录库就读不出来了。App 遇到这种情况会直接报错，不会悄悄换一个新密钥，以免掩盖数据丢失。

以后数据量大到需要全文索引时，可以重新评估 SQLCipher。
