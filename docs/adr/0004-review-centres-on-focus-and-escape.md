# 复盘围绕主线和逃开，而不是只回顾事情

复盘从「今天做了哪些事情、哪件没做好」改为四步：各条**主线**推进得怎么样、在哪里**逃开**了、把卡住的难题拆成能回答的小问题、定下明天第一步。原因：2026-11-01 的试复盘发现，Jonas 碰到没有入口的难题时会转去做马上能看到结果的事，重要的事因此断线；而问题一旦拆成可选的小问题，他能很快想得很深。他自己选的**长期方向**正是这两点。

同一天否定了「每天只选一个重点」：他同时推进几条线，用 AI 时更是一边等 AI 一边做另一件。所以改为每条主线每天定**今天的产出**和**时间上限**，用实际用时校准估算，拿过去的自己作比较，而不是拿别人的速度。逃开也随之定义为「球在用户手里时切走」，AI 还在处理时的切换不算。

这和 ADR 0001 的「不做跑偏判定」不冲突：跑偏是按内容给行为贴标签，被否定了；逃开只看用户该接球时有没有接，只以提问说出，用户确认才算，不计分。代价是：主线和产出需要用户维护（可以不填，退回只看事情和待办）；把正常的切换误判成逃开会让复盘显得在指责人，所以只在复盘时说、白天不提醒，门槛用真实记录调整。
