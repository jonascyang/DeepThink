| 复盘 / LLM | 非范围 | **在范围**：一天的完整理解交云端模型；本机小模型只做可选片段摘要 |
| 产品名 | DeepThink | **Think My Day** |

## 1. 一句话

Think My Day 是 Jonas 个人用的 macOS 菜单栏 App：在本机持续读取你正在看的窗口文字，推断任务、行为和跑偏时刻，晚上给出一份「你今天实际做了什么」的复盘。数据只存本机，发给云端模型的内容由你控制，并且常驻可见。

## 2. 背景与问题

Jonas 是加密研究员，并行使用多个 AI Agent、浏览器研究、聊天工具和文档。一天结束时，他不清楚时间去了哪里、什么时候被打断或跑偏。只记「哪个 App 开了多久」无法回答「当时在做什么任务」，也看不出 ADHD 式的碎片化切换。

只靠 Agent 日志和 Chrome History（v0.1 方案）覆盖面太窄：写文档、读网页、聊天、终端里的工作都看不到。所以 v0.2 改为以屏幕文字为主信号，向 Littlebird 类产品看齐，但全部本地存储、可控外发。

## 3. 目标与非目标

### 目标（v1）

1. 以「读屏幕文字」为主信号，推断每一段时间的任务类型与主题。
2. 识别碎片化与跑偏：焦点切换频率、短时反复切回、离开（AFK）与空档。
3. 一天结束生成复盘：时间线、任务段落、跑偏/碎片化提示、建议。
4. 全部原始数据在本机，库加密；写入前脱敏。
5. 外发给云端模型的内容由用户控制，复盘页常驻显示「今天发过什么」。
6. 无需 Apple 开发者账号即可稳定安装，重装后授权尽量保留。

### 非目标（v1）

- 周期性全屏截图与录屏；击键监听；剪贴板监听。
- 跨设备同步、iCloud、账号体系；iPhone。
- Mac App Store 分发。
- 自带或自训练模型（本机小模型仅用系统自带的，且可选）。
- 解密 ChatGPT Mac 缓存；把 Claude Desktop / Muse 等当作有完整日志的一等数据源。

## 4. 用户与场景

| 场景 | 用户要做什么 | 系统提供 |
| --- | --- | --- |
| 晚间复盘 | 看今天各时段实际在做什么 | 任务时间线 + 云端模型生成的日复盘 |
| 找跑偏 | 想知道什么时候被带走 | 切换频率、反复切回、离开/空档标注 |
| 控制外发 | 想确认发了什么 | 复盘页「今天发给云端的内容」常驻列表 |
| 敏感工作 | 开着钱包、密码管理器、聊天 | 三档 App 策略，敏感 App 不读取 |
| 重装升级 | 新版本不想重新授权 | 固定签名 + 授权保留检查 |

## 5. 采集方案

### 5.1 信号分层

| 层 | 信号 | 用途 | 说明 |
| --- | --- | --- | --- |
| 主 | 窗口可见文字 | 判断任务与主题 | 辅助功能（Accessibility）读取；读不到则对单个窗口本机文字识别（OCR） |
| 主 | 焦点切换、窗口标题 | 切换路径、碎片化 | NSWorkspace 事件驱动 |
| 主 | 焦点输入框字数增减 | 区分「在写」和「在看」 | 只读获得焦点的输入框内容长度的变化，不监听键盘，不存内容 |
| 主 | 网页 URL / 标题 | 浏览研究归类 | Chrome 通过自动化（AppleScript）取当前标签 URL 与标题；正文读取方式由 M0b 实测 |
| 辅 | AFK、睡眠 / 唤醒 / 锁屏 | 空档、离开 | 空闲阈值默认 3 分钟（可选 1/3/5） |
| 辅 | Claude Code / Codex 会话 | 补充任务主题 | 只存会话主题等瘦字段，**不当主依据** |
| 可选 | Biome `App.InFocus` | 采集缺口见证 | 非主路径 |

### 5.2 每个 App 三档（默认由产品定，用户可在设置里逐 App 修改）

| 档位 | 行为 | 默认 App |
| --- | --- | --- |
| 完整读取 | 读窗口文字 | 浏览器、文档、编辑器、终端、Agent |
| 只记标题 | 只记窗口标题，不读正文 | 微信、飞书、邮件、Slack 等含他人原话的 App |
| 完全排除 | 不读、不记，只留「被排除」的占位 | 密码管理器、钱包、银行 |

密码输入框（AXSecureTextField）任何档位都不读。无痕窗口不采详细内容。

### 5.3 采样策略（待 M0b 实测定参数）

- 事件触发为主：焦点变化、标题变化、输入框字数变化；静止时低频采样（初始 5 秒，M0b 后调整）。
- 文字入库做去重与差分，同一屏不重复存。
- 读不到文字（Electron、自绘界面等）：先尝试开启 `AXManualAccessibility`；仍读不到再做单窗口 OCR，限频（初始每 30 秒最多一次），图片识别后立即丢弃。

## 6. 存储、加密与保留

| 项 | 要求 |
| --- | --- |
| 库 | 本机单库 SQLite（WAL），事件追加 + 游标，崩溃可重放 |
| 加密 | **库加密，密钥存钥匙串**；无密钥无法读库 |
| 保留 | 原始屏幕文字默认 **30 天**后清理；复盘摘要、统计可更久，保留期可在设置修改 |
| 脱敏 | 写入前：API key、私钥、助记词（BIP39 ≥12 词）、JWT、URL query 一律替换或丢弃 |
| 备份 / 导出 | `VACUUM INTO` 一致性快照；按日期导出 |

## 7. 复盘与云端模型

### 7.1 分工

- **云端模型**：一天的完整理解（任务段落、行为解释、跑偏原因、建议），输入为脱敏后的分段摘要。由用户选择提供方、填写自己的 key。
- **本机小模型**：用 Mac 自带的系统小模型，**只做可选的片段摘要**；没有它产品也完整可用，不需要自带模型。
- **本地规则层（无网络）**：时间线、切换次数、空档、碎片化阈值（≥30 次焦点切换/小时）。不联网也能出基础复盘。

### 7.2 外发控制

- 默认不外发，用户开启后才调用云端模型。
- 发送前预览「将发送的内容」；可按 App、按时间段排除。
- 复盘页**常驻显示今天已发送的内容**与发送次数。
- LLM 调用走可替换的 `ReviewProvider` 接口（OpenAI 兼容、Anthropic 已实现），key 存钥匙串。本期不依赖任何托管后端。

### 7.3 复盘页术语

记录、时间线、复盘、空档、离开、建议、摘要（文案以 copy.md 为准）。

## 9. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 资源 | 目标：平均 CPU 低（M0b 实测后定具体数字）；内存常驻小；OCR 限频 |
| 可靠性 | WAL；事件与游标同事务；schema 前向迁移 |
| 隐私 | 无击键、无剪贴板、无全屏截图；读取内容写入前脱敏；原始文字 30 天 |
| 网络 | 默认零网络；仅在用户开启云端复盘时向其选择的提供方发送 |
| 打包 | 通用二进制（arm64 + x86_64）`.app`，`LSUIElement` 菜单栏，`SMAppService` 登录项 |

## 10. 隐私总览

| 记 | 不记 |
| --- | --- |
| 前台 App、切换时刻、窗口标题 | 键盘按键内容、鼠标轨迹、剪贴板 |
| 「完整读取」档 App 的窗口文字（脱敏、加密、30 天） | 排除档 App 的任何内容；密码输入框 |
| 输入框字数增减 | 输入框里的文字本身 |
| 读不到文字时的单窗口识别结果 | 截图图片（识别后丢弃）；全屏录屏 |
| Chrome 当前标签 URL（去 query）与标题 | 无痕窗口详细内容 |
| AFK / 睡眠 / 锁屏边沿 | 锁屏后窗口内容 |

残余风险：窗口文字可能含他人原话或未覆盖的秘密形态，靠三档策略 + 脱敏 + 外发预览降低；Accessibility 权限只授给签名的 `.app`。

## 11. 签名与安装

- 不走 Mac App Store、不要求 Apple 开发者账号：用一张固定自签证书给 `.app` 签名。
- 已在云端验证：用同一证书重新构建，代码身份（designated requirement）保持一致，因此辅助功能授权**预期**可在升级后保留；真机是否真保留，由 M0b 的「启动记录」验证。
- 代价：首次打开需右键 → 打开；无公证。若真机验证失败，再评估是否开通 Developer ID。
- 证书与私钥只放本地，**不提交 git**。
- 需要的授权：辅助功能（必须）、自动化 → Chrome（取 URL）、屏幕录制（仅 OCR 兜底，可选）、登录项。

## 14. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Electron / 自绘界面读不到文字 | 任务判断变弱 | `AXManualAccessibility` → 单窗口 OCR；M0b 量化 |
| 自签证书授权不保留 | 每次升级要重新授权 | M0b 验证；备选 Developer ID |
| 读取内容含他人原话 | 隐私面扩大 | 三档、脱敏、外发预览、30 天清理、库加密 |
| 云端模型输出不稳或误判跑偏 | 复盘不可信 | 本地规则层兜底；建议类文案保守 |
| macOS 更新改变辅助功能行为 | 读取失效 | 健康提示 + 探测版回归 |
| 电量与 CPU | 影响日常使用 | 事件驱动、限频、M0b 实测 |
