# Triage labels

工程 skills 提到以下角色时，使用对应的 GitHub 标签。

| 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，AI 可执行 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不处理 |

复用已有的同名标签；不覆盖它们的描述或颜色。
