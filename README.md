# Think My Day

Jonas 个人用的 macOS 菜单栏 App：在用户选择的应用范围内读取窗口文字，像会议纪要一样记录一天的时间、行为、App、内容与文档，再根据具体内容及前后任务关系分析可能的跑偏。

产品需求见 [docs/PRD-采集与存储.md](docs/PRD-采集与存储.md)（PRD v0.3，2026-10-29；模型接入方式待定）。当前仓库只有需求文档，没有 Swift 实现或可运行 App。

## 要点

- 先记录事实：时间、行为、App、窗口、内容摘录与相关页面或文档；同一桌面同时可见的多个窗口分别记录位置、内容与操作焦点。
- 内容是任务归纳与跑偏判断的主要依据，切换次数、App 名称和停留时长只作辅助；推断关联来源，内容不足时明确无法判断。
- 每个 App 三档：完整监控 / 只记标题 / 完全排除。选择完整监控即允许读取可见窗口全部可读取文字，包含普通输入框；密码框排除与脱敏继续生效。本机监控与外发分别控制。
- 主信号是辅助功能读取的窗口文字；OCR 总开关与各 App 开关默认关闭，用户选择开启后才作兜底，图片不落盘。Chrome 页面与历史、焦点变化及 Claude / Codex 会话主题补充上下文。
- 本机 SQLite，库加密、密钥在钥匙串，原始屏幕文字默认保留 30 天；写入前脱敏。
- 模型负责内容整理、任务归纳与跑偏分析；可调用 LLM API，也可接其他服务（如 Grok Bot），方式尚未决定。发送前预览，复盘页常驻显示今天发过什么、发给谁；没有模型时仍可回看本地记录。
- 本轮只修订需求文档，暂不进行探测、安装、真实工作验证或模型调用；使用固定自签证书，不开通 Developer ID。
