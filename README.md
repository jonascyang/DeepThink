# DeepThink

本地版 Littlebird + ADHD 复盘：让 AI 看着你的 Mac，理解你在做什么任务、实际做了什么、什么时候跑神了，并主动还原你的一天。

- 数据来源：辅助功能读屏幕文字（主力）、读不到时识别单个窗口截图（图片立即删除）、Chrome 历史、App 切换 / AFK / 睡眠锁屏。
- 数据只存在本机 SQLite；发给 AI 前先脱敏。密码框、密码管理器、钱包不读；私钥、助记词、API 密钥存储前替换。
- 全部用 Swift 实现，仅 macOS。

当前需求见 [docs/PRD-v0.2-数据获取.md](docs/PRD-v0.2-数据获取.md)（草案，2026-10-28）。早期的 [PRD v0.1（采集与存储）](docs/PRD-采集与存储.md) 已被 v0.2 取代，保留作历史参考。
