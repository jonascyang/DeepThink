# Think My Day

Jonas 个人用的 macOS 菜单栏 App：从「开启一天」起在本机完整记录电脑上发生的事，白天由 AI 整理成一件件事情，任何时候都可以和 AI 对话复盘：今天做了什么、哪件事没做好。

产品需求见 [docs/PRD.md](docs/PRD.md)（PRD v0.4，2026-10-29；界面布局待设计）。术语见 [CONTEXT.md](CONTEXT.md)，关键决定见 [docs/adr/](docs/adr/)。当前仓库只有需求文档，没有 Swift 实现或可运行 App。

## 要点

- 点「开启一天」才开始记录：填写待办、选择不看名单；显示比计划开始时刻早了还是晚了。点「结束一天」停止记录。
- 不看名单之外的所有 App 完整记录：窗口文字（含普通输入框）、多窗口布局与焦点、Chrome 网址；读不到文字时默认对单个窗口做本机 OCR，图片不落盘。密码框、钱包与密码管理器页面、无痕窗口永远不读。
- AI 白天每 15 分钟左右把新增记录整理成事情；发现新工作时弹通知询问是否加入待办。待办只有用户本人能勾选。
- 复盘是对话：AI 概述一天的事情，以「观察 + 提问」指出哪件事没做好，可以给总结性建议；不做跑偏判定，不打分。
- 模型由用户配置：各家官方 API 或兼容接口，整理与对话分别指定；订阅可经 magpie 等本机网关接入。记录下来的内容都可以外发，不逐次确认。
- 本机 SQLite，库加密、密钥在钥匙串，写入前脱敏；原始记录默认保留 30 天，事情、待办与对话永久保留。
- 使用固定自签证书，不开通 Developer ID。

## 明确不做

周期全屏截图与录屏、击键监听、剪贴板监听、跑偏判定与打分、发送记录界面、iPhone、iCloud、Mac App Store。
